# Warzone Hacks — hacksforwarzone.com

Astro static site for **Call of Duty: Warzone** hacks (ESP, aimbot, wallhack, item ESP, radar).

- **Domain:** https://hacksforwarzone.com
- **Stack:** Astro 7, React 19, Tailwind CSS 4, Cloudflare Workers
- **Forums:** `/forums/` (replaces blog/guides)

## Develop

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```

Output in `dist/`. **Do not push until explicitly requested.**
